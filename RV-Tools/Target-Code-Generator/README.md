# Target Code Generator

A simple Python tool for generating target codes for Remote Viewing sessions.

## Files

- `target_code_generator_pl.py` — Polish version
- `target_code_generator_en.py` — English version

## Usage

Run one of the files with Python:

```bash
python target_code_generator_en.py
```
```bash
python target_code_generator_pl.py
```
Purpose

This tool generates simple target codes that can be used to organize and label Remote Viewing sessions.
Target codes are optional — they are helpful for structure and record-keeping, but they are not required for a session itself.
